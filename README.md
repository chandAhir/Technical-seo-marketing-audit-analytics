# 📊 Technical SEO & Marketing Performance Analytics 

## 🚀 Executive Overview
This project presents an end-to-end data audit analyzing multi-channel revenue attribution, 12-month organic traffic decay, and prioritized technical SEO bottlenecks. It translates raw analytics and crawl datasets into actionable executive insights and strategic sprint roadmaps.

---

## 🎯 Key Objectives & Scope
- Channel Revenue Attribution: Analyzed revenue distribution to identify CAC risks and paid search dependencies (32.7% share).
- Organic Traffic Decay: Visualized a 12-month organic session decline to highlight indexability and content freshness issues.
- Technical SEO Remediation: Prioritized 8 critical technical issues across 1,000+ affected pages (e.g., Meta Noindex, URL Length, 4xx Errors).
- C-Suite PDF Report: Automated the generation of a clean, presentation-ready PDF audit report.

---

## 📈 Visual Highlights
- Donut Chart: Multi-channel revenue share.
- Line Chart: 12-month organic traffic decay trend.
- Horizontal Bar Chart: Technical SEO issues prioritized by affected page volume.
